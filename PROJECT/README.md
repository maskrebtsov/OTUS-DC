# Проектная работа
Тема: Бесшовная миграция инфраструктуры действующего ЦОД с технологии vPС на технологию VXLAN

## Цели работы:
Разработка и экспериментальная верификация методики бесшовной миграции сетевой инфраструктуры действующего центра обработки данных с классической архитектуры vPC/HSRP на фабрику VXLAN EVPN на существующем оборудовании с сохранением строгой изоляции VRF и маршрутизацией всего межсегментного трафика исключительно через межсетевые экраны периметра без прерывания работы пользовательских сервисов.

### Для достижения поставленной цели в работе решаются следующие задачи:
1.	Провести сравнительный анализ существующих подходов и вариаций миграции действующих сетей ЦОД на архитектуру VXLAN EVPN по техническим, эксплуатационным и экономическим критериям.
2.	Спроектировать целевую архитектуру фабрики Spine–Leaf, обеспечивающую оптимальную маршрутизацию внутри каждого VRF и направление всего Inter-VRF трафика через пограничные узлы (Border Leaf) на межсетевые экраны (DC-EXT).
3.	Разработать пошаговый алгоритм бесшовной миграции инфраструктуры с использованием временного межсетевого моста и регламента быстрого аварийного отката (Rollback).
4. Развернуть имитационную модель в среде Cisco Modeling Labs (CML) и провести экспериментальную проверку сходимости протоколов, потерь пакетов, отказоустойчивости и корректности прохождения трафика через зоны безопасности межсетевых экранов.
